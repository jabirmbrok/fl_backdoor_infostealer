# Channel-aware backdoor attacks on federated infostealer classification

## What this repo is

Experiment code, dataset, results and paper source for *Channel-Aware Backdoor Attacks Against
Federated Infostealer Malware Classification Using Dynamic API-Call and Network Representations*
(IWBIS). Status: **accepted with minor revisions** — preparing the camera-ready version.

Start every session with `/lab-status`.

## Conventions

1. Numbers flow one way: `results/<run>/*.json` -> `export_runs.py` -> `results/runs.csv` ->
   `aggregate.py` -> `results/tables/` -> paper. Never type a result from memory into the paper,
   a table, or a message.
2. `results/runs.csv` is generated, not hand-edited. Re-run `export_runs.py --force` after new runs.
   `check_runs.py` validates it and lists what is still pending.
3. ASR is stored as raw counts (`asr_hits` out of `asr_n` = 15), never as a ratio.
4. One GPU job at a time (single RTX 3080, 12 GB). Log to `logs/<exp_id>.log`.
5. Seeds: 42, 123, 2026 (paper) and 7, 99 (camera-ready additions). The **split is re-drawn per
   seed** (`dataset/splits/split_rgb_seed<N>.csv`), so a new seed needs a new split file first.
6. Per-seed values always accompany mean +/- std (ddof = 1). An ASR spread >= 0.5 across seeds is
   described as bimodal, never as a mean.
7. Never modify `dataset/processed/`, `dataset/splits/`, or any existing `results/<run>/` directory.
   Hyperparameters stay as in the paper unless a Tier 3 matrix row says otherwise.
8. New runs get a new config file under `configs/camera_ready/`; do not edit the configs that
   produced the submitted results.
9. Log every paper edit in `docs/CHANGES.md` with the reviewer item it addresses. Ask before
   deleting anything.

## Experimental facts

The authoritative version is `docs/CODE_FACTS.md`. Short form: 5 families x 100 samples, stratified
350/75/75 re-drawn per seed; 128x128 RGB-stack (R = API tile, G = network tile, B = fusion);
ResNet18 from scratch, AdamW, lr 1e-4, wd 1e-4, batch 16, no augmentation; FedAvg, 5 IID clients of
70 samples (14 per family), 50 rounds x 2 local epochs, final-round model reported; attack =
AgentTesla -> FormBook, client 0, pure data poisoning, white 12x12 trigger bottom-right, poison rate
20% of the attacker's 14 source samples = **2 images per round, resampled each round**; Multi-Krum
f = 1, |S| = 2; ASR over the 15 AgentTesla test samples.
